# Attendee instructions: LAB682

Welcome to **LAB682: Can't secure what you can't see. Find every AI agent in your org**.

Follow the complete [lab instructions](LabInstructions.md) in your prepared LAB682 environment.

## Lab flow

1. Manage agent identities at scale with Microsoft Agent 365 and Microsoft Entra.
2. Govern agent permissions and sponsorship with access packages and lifecycle workflows.
3. Protect agent web access, file uploads, and MCP connections with Global Secure Access.

## Environment requirements

The walkthrough requires the preconfigured LAB682 tenant, Windows virtual machine, lab-assigned credentials, agent identities, and policies. This repository contains instructions, not an environment deployment.

The lab instructions use Skillable-specific syntax, including credential tokens, variables, task checkboxes, and page breaks. These resolve in a launched Skillable lab and may not render as interactive controls on GitHub.
