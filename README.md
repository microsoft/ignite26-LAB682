# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB682: Can't secure what you can't see. Find every AI agent in your org
### Session description

AI agents can spread across platforms, access organizational resources, and continue operating as people change roles or leave the organization. In this hands-on lab, discover and inspect agent identities with Microsoft Agent 365 and Microsoft Entra Agent ID, govern their permissions and sponsorship, and use Global Secure Access to protect agent access to web resources.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Launch the LAB682 environment provided by your session facilitator.
2. Use the lab-assigned credentials and resources; the environment is shared with other attendees.
3. Follow the step-by-step guidance in [`instructions/README.md`](instructions/README.md).

#### On your own

This lab is only available at in-person sessions at Ignite 2026. You may review the [Lab Instructions](instructions/README.md) but a full lab environment is not provided publicly.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Discover agents across platforms and inspect their identities, blueprints, and inherited permissions with Microsoft Agent 365 and Microsoft Entra Agent ID.
- Govern delegated and autonomous agent permissions through access packages, and maintain accountable sponsorship with lifecycle workflows.
- Protect agent web access, file uploads, and remote MCP connections with Global Secure Access, and correlate enforcement decisions with traffic logs.
